桌面生物 / Desktop Creatures
v1.1.0-preview.1 · Windows 11 x64 便携预览版

使用方法
1. 完整解压 ZIP，不要只从压缩包中单独运行 EXE。
2. 双击 desktop-creatures.exe。需要 Windows 11 x64 和 WebView2 Runtime。
3. F12 是紧急隐藏键。应用为桌面透明覆盖层，可通过托盘菜单退出。

这是未签名的预览版，Windows SmartScreen 可能提示确认。已通过构建绑定验证和
启动烟测；鼠标穿透、焦点、托盘与多显示器行为尚未完成全面人工验收。
游戏在本机保存进度；本包不连接 Steam。

English
Desktop Creatures v1.1.0-preview.1 is a portable preview for Windows 11 x64.
Extract the full ZIP, then double-click desktop-creatures.exe. WebView2 Runtime
is required. F12 hides the overlay immediately; exit from the tray menu.
The build is unsigned and may prompt Windows SmartScreen. Build binding and
startup smoke tests passed; full manual checks of click-through, focus, tray,
and multiple displays are still pending. Saves stay local. Steam is not connected.
