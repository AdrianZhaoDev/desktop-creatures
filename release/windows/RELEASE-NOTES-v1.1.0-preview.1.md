# 桌面生物 v1.1.0 预览版 1

**Windows 11 x64 便携版**：下载 `Desktop-Creatures-v1.1.0-preview.1-Windows-x64.zip`，完整解压后双击 `desktop-creatures.exe`。需要 WebView2 Runtime。可用 `SHA256SUMS.txt` 校验下载文件。

本版以 r21 全屏菜单代码为基础，提供人偶与青蛙协作清洁、捕虫、房屋守护、工具、升级和本地存档。公开构建将受限的 R19 角色替换为项目原创 S06 素材，窗口及托盘标题统一为“桌面生物”。源码、中文默认及英文 README、真实游戏画面 GIF 和许可声明均已公开。

构建经过 TypeScript 检查、9 项候选测试、固定资源清单和原生绑定验证；最终 ZIP 内的 EXE 通过了启动烟测。此包**未签名**，且鼠标穿透、焦点、托盘与多显示器行为尚未完成全面人工验收，所以标为预览版。`F12` 可紧急隐藏覆盖层。它不连接 Steam。

代码使用 MIT；项目原创素材使用 CC BY 4.0；压缩包包含第三方组件声明。问题请在仓库 Issues 反馈。

## English

**Portable preview for Windows 11 x64.** Download the ZIP above, extract it fully, and double-click `desktop-creatures.exe`. WebView2 Runtime is required; `SHA256SUMS.txt` contains the download hash.

This release uses the r21 full-screen menu code and replaces the restricted R19 runtime character with project-created S06 assets. It includes the cleaner and frog campaign, tools, upgrades, and local saves. Source, bilingual README files, a GIF recorded with the real game renderer, and license notices are public.

TypeScript checks, nine candidate tests, fixed-resource checks, native binding verification, and a smoke test of the packaged EXE passed. The build is unsigned and full manual acceptance of click-through, focus, tray, and multiple displays remains pending. Press `F12` to hide the overlay immediately. Steam is not connected.
